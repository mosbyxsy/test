# Node.js 脚本

提供目录扫描和本地 HTTP 服务。使用 Node.js 内置模块，无需安装 npm 依赖或构建。[返回项目总览](../README.md) · [浏览器使用说明](../file-browser/README.md)

## 环境与运行

需要 Node.js 20 或更新版本。

在项目根目录执行：

```bash
node scripts/scan.mjs
node scripts/serve.mjs
```

访问 http://127.0.0.1:8080 。扫描完成后进程退出；服务持续占用当前终端，按 `Ctrl+C` 停止，不会自动转为后台服务。

## 扫描目录

```bash
node scripts/scan.mjs              # 扫描终端当前目录
node scripts/scan.mjs "D:\资料"    # 指定扫描目录
```

- 输出固定为项目内的 `file-browser/catalog-data.js`，提供 `window.FILE_CATALOG`。
- 记录文件元数据、目录统计和读取错误，不读取文件正文；符号链接只记录、不跟随。
- 默认跳过所有层级的 `.git` 目录，并读取根目录及子目录中的 `.gitignore`。
- 生成结果通过同目录临时文件原子替换，结束后输出数量、大小和错误摘要。

相对扫描路径以终端当前目录为基准，页面资源和索引输出位置以项目位置为基准。文件或忽略规则变化后重新扫描并刷新页面；移动项目或扫描目录后也需重新扫描。

## 启动服务

```bash
node scripts/serve.mjs       # 默认端口 8080
node scripts/serve.mjs 8090  # 自定义端口
```

启动前先生成索引。服务监听 `127.0.0.1`，同时提供项目页面和扫描目录中的文件；访问其他扫描目录时不需要移动页面资源。

仅开放索引内的普通文件，校验真实路径以限制越界访问。支持 GET、HEAD、下载和媒体 Range 请求，原始 HTML 等内容使用沙箱响应头约束。适用于本机目录浏览。

重新扫描后服务自动识别索引变化，无需重启；修改服务代码后需重启。使用 IDE 或其他静态服务时，这里的服务脚本和缓存不参与请求处理。

## 脚本职责

| 文件 | 职责 | 是否直接运行 |
| --- | --- | --- |
| [scan.mjs](./scan.mjs) | 扫描目录并生成索引 | 是 |
| [serve.mjs](./serve.mjs) | 提供页面、文件预览和下载 | 是 |
| [scan-ignore.mjs](./scan-ignore.mjs) | 解析、匹配 `.gitignore` 规则 | 否，由扫描器调用 |
| [server-cache.mjs](./server-cache.mjs) | 缓存目录索引和静态资源 | 否，由服务调用 |

服务缓存保存在 Node 进程内存中，不创建磁盘缓存目录。复用索引解析、静态文件读取及 gzip 结果，文件变化后更新；关闭服务后清空。原始预览文件不进入这份缓存。

## 常见问题

- **找不到 `node`**：确认已安装 Node.js 并加入 PATH，安装后重新打开终端。
- **找不到脚本**：确认在项目根目录运行，或使用脚本的绝对路径。
- **服务启动失败**：先运行扫描；端口被占用时换一个端口。
- **文件未显示或读取失败**：检查 `.gitignore`、文件权限，以及文件是否在扫描后移动或删除，再重新扫描。

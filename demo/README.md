## 建议检查顺序

1. 正常文件：打开预览，检查内容、详情、名称复制、地址复制与下载。
2. 布局交互：切换文件、页面内全屏、关闭预览，并在窄屏检查滚动。
3. 边界文件：确认大文本按需加载，空内容可正常打开，损坏文件失败后仍可下载。
4. 延迟加载：刷新后打开网络面板，确认仅在打开相关格式时加载对应预览模块及解析库。

损坏文件无法预览属于预期结果；浏览器原生媒体和桌面 PDF 的错误界面可能不同。本目录不覆盖 Office 大于 20/50 MB、解析超时、读取权限失败和符号链接等全部边界场景。

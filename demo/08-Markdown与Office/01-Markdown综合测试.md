# Markdown 综合预览

本文件用于验证阅读模式、源码切换、相对图片、表格与安全清理。所有数据均为演示数据。

## 常见排版

这是 **加粗**、*斜体*、~~删除线~~ 与 `行内代码`。

> 引用内容应以独立样式呈现，且不影响文件列表。

- [x] 标题和段落正常显示
- [x] 表格正常显示
- [ ] 手动验证手机滚动

1. 打开本文档。
2. 切换“查看源码”。
3. 切回“阅读模式”。

| 文件格式 | 阅读能力 | 状态 |
| --- | --- | --- |
| Markdown | 标题、表格、代码块、图片 | 支持 |
| DOCX | 正文、列表、图片、表格 | 支持 |
| Excel | 工作表切换、200 行分页 | 支持 |
| PPTX | 按页显示文字、表格与图片 | 支持 |

| 文件 | 建议验证内容 |
| --- | --- |
| 01-Markdown综合测试.md | 标题、表格、任务列表、代码块、相对图片和源码切换 |

## 异常文件

Office 损坏样例已统一放在 [09-边界与损坏](../09-边界与损坏/README.md)。打开后应显示错误或不支持提示，同时保留下载操作。

## 懒加载

刷新页面后，在浏览器网络面板中检查：未打开对应格式时，不应请求 Marked、DOMPurify、JSZip 或 SheetJS。主页面复用已加载的预览模块；Office 在按需启动的 Worker 中解析，切换文件时终止旧 Worker，新 Worker 可能再次请求解析库。

Office 以阅读内容为目标，不要求精确还原排版。本目录用于正常内容验证，不覆盖超大 Office、加密或解析超时。

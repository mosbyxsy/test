# CSV 与 TSV 表格测试

[返回 Demo 总览](../README.md)

| 文件 | 预期效果 |
| --- | --- |
| 01-CSV引用与分页.csv | 451 行（含首行），默认 A/B/C 列标，共 3 页；启用首行表头后剩余 450 条记录 |
| 02-TSV引用与换行.tsv | 引用字段内的制表符、换行和双引号保留在同一单元格 |
| 03-UTF8-BOM.csv | 自动识别 BOM，不显示在首个单元格中 |
| 04-UTF16-LE.csv | 自动识别 BOM，中文正常显示 |
| 05-GB18030中文.csv | 手动选择 GB18030 / GBK 后中文正常显示，源码沿用所选编码 |
| 06-空文件.csv | 显示 0 行，不能翻页 |
| 07-仅表头.csv | 启用首行表头后只显示表头，数据为 0 行 |

`00123` 必须保留前导零，`=1+2` 和 `=SUM(1,2)` 只展示原文，不执行公式。HTML 字符串作为普通文字显示。
